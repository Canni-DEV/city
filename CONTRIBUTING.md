# Contributing

City is a public source repository maintained by Canni-DEV with Codex. External contributions are not accepted at this stage, including unsolicited pull requests and feature requests.

Internal work follows milestone branches, Conventional Commits, and pull requests into `main`. Each pull request must identify covered requirement IDs, include the commands and manual QA performed, name the tested graphics backends, attach relevant screenshots, report performance observations, and update affected documentation. A milestone pauses for review before the next one begins.
