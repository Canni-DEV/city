# Web application instructions

Own routes, feature composition, persistence adapters, workers, and rendering. Domain mutation goes through `@city/core`; the rendered scene (including M3.6 agents, M3.6.1 sidewalks, and M3.6.2 vehicles) is derived from `CityDocumentV1`. Prefer instancing by asset and variant for city kits and runtime vehicles; runtime agents use skinned meshes. Reconstruct one `DriveNetwork` per open document and share it with the vehicle mover, Traffic lanes overlay, and inspector. Preserve stable entity-to-instance mappings, and keep WebGPU/WebGL 2 parity. Development-only routes must not ship. Validate keyboard flows and both backends for user-visible changes. Update UX, rendering, persistence, deployment, and testing documents as applicable.
