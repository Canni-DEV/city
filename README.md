# City

City is a browser-based procedural city sandbox and editor built with TypeScript, React, and Three.js.

The repository currently contains the original Kenney city assets. Project scaffolding and the complete implementation specification are delivered in milestone M0.

## Assets

The asset packs under `assets/` are distributed by [Kenney](https://kenney.nl/) under CC0 1.0. Each pack retains its original license file.
