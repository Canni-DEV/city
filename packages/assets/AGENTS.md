# Assets package instructions

Own catalog schema, generation, overrides, validation, and runtime-copy tooling. Never alter files under `/assets`. Generated metadata must be reproducible, stable-ID based, and validated before use. Review exceptions through `catalog/overrides.json`, not ad-hoc application code. A valid city-kit catalog has exactly 213 unique GLB entries, valid paths and footprints, and complete road connectors. M3.6 adds generated protagonist GLBs outside `/assets`; do not pack source FBX. M3.6.2 catalogs Kenney Car Kit bodies as pack `cars` without packing wheels, debris, or karts, and measures `driveProfile` / `vehicleBounds` from untouched GLBs. Update `ASSET_CATALOG.md` for catalog changes.
